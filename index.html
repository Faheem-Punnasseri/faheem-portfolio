06 / TROUBLESHOOTING

Problems traced across layers.

The strongest integrations are often built by following a fault from interface to field equipment.

Unsupported Zigbee device

Problem · No native fingerprint support.

Action · External converter and MQTT discovery troubleshooting.

Result · Relay control tested successfully.

MQTT control unavailable

Problem · Entities unavailable or uncontrollable.

Action · Traced broker ACL and topic permissions.

Result · Discovery, state and commands restored.

Valid zero values lost

Problem · Zero daily totals skipped by timeseries logic.

Action · Identified truthiness checks and explicit validity handling.

Status · Corrective production validation undertaken.

Stale trip address

Problem · Trip end reused old location context.

Action · Separated geocoding and preserved event state.

Result · Verified through a natural trip event.

KNX / HVAC mismatch

Problem · Application mode differed from equipment response.

Action · Traced plugin, GA, DPT and Intesis modes.

Result · Mapping and feedback behaviour corrected/tested.

Intercom call control

Problem · Indoor-station ringing/hangup varied by topology.

Action · PowerShell tools and raw message testing across old/new stations.

Status · Raw hangup accepted on the older station; new-master behaviour remained problematic.
